# Diabetes Disease Prediction

## Project Overview
Diabetes Disease Prediction is a Machine Learning project that predicts whether a person is likely to have diabetes based on medical information.

The project uses the Pima Indians Diabetes Dataset and applies data preprocessing, exploratory data analysis, model training, and performance evaluation.

## Objectives
- Analyze patient health data.
- Perform data cleaning and preprocessing.
- Visualize important dataset features.
- Train and compare multiple Machine Learning algorithms.
- Predict diabetes using the trained model.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly

## Machine Learning Algorithms
The project evaluates the following algorithms:
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Support Vector Machine (SVM)
5. K-Nearest Neighbors (KNN)
